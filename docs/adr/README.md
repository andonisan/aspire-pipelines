# Architecture Decision Records (ADR)

Este directorio contiene los registros de decisiones arquitecturales (ADR) del proyecto Aspire Pipelines.

## ¿Qué es un ADR?

Un ADR documenta una decisión arquitectural importante junto con su contexto, consecuencias, y alternativas consideradas. Ayuda a equipos presentes y futuros a entender *por qué* se tomaron ciertas decisiones.

## Formato

Cada ADR sigue esta estructura:

1. **Título**: Número y descripción breve
2. **Estado**: Propuesto | Aceptado | Deprecado | Supersedido
3. **Contexto**: Problema o situación que motiva la decisión
4. **Opciones**: Alternativas consideradas con pros/contras
5. **Decisión**: Opción elegida y justificación
6. **Consecuencias**: Impacto positivo y negativo de la decisión
